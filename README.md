# ritiksundaram.github.io

Personal site for Ritik Sundaram, live at [ritiksundaram.github.io](https://ritiksundaram.github.io).

Single-file static site — no build step, no dependencies. Everything lives in
`index.html`: styles in `<style>`, the hero animation in `<script>`. Colors are
CSS variables at the top of the style block. Hosted on GitHub Pages.
